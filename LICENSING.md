# Licensing

Bounded Origin uses a mixed-license model.

## Runtime and implementation

Except for `bounded-origin-api` and third-party material identified separately, Bounded Origin is licensed under the **GNU Affero General Public License v3.0 only** (`AGPL-3.0-only`).

The full license text is available in `LICENSE` and `LICENSES/AGPL-3.0-only.txt`.

## Public API

The complete `bounded-origin-api` module is licensed under the **Apache License 2.0** (`Apache-2.0`).

The full license text is available in `bounded-origin-api/LICENSE` and `LICENSES/Apache-2.0.txt`.

The API is intentionally permissive so applications and external integrations can depend on the Bounded Origin contract without adopting the runtime license for their own independent code.

## Commercial licensing

Alternative commercial licensing for AGPL-covered Bounded Origin components can be arranged with the copyright holder for organizations that require different terms.

Commercial licensing does not change the rights already granted under the AGPL or Apache licenses.

## Third-party material

Third-party and generated material retains its own applicable license and copyright notices. Nothing in this repository relicenses third-party material under Bounded Origin's project licenses.

## Machine-readable declarations

`REUSE.toml` records the license assignments for project-owned files without adding license headers to every source file.
